## Image Pyramids: Multi-Scale Signal Representation

Image pyramids are a foundational multi-scale representation technique in computer vision and image processing. A signal or image is repeatedly smoothed and subsampled to produce a stack of progressively lower-resolution versions, forming a pyramid shape. Pyramid representations are predecessors to scale-space representation and multiresolution analysis, and remain widely used as efficient approximations to full scale-space methods.

## Key Concepts

- **Lowpass pyramid**: Built by smoothing with a filter then subsampling (typically by factor 2 in each dimension); each level has lower resolution and increased smoothing
- **Bandpass pyramid**: Formed by computing the difference between adjacent lowpass pyramid levels after interpolation, capturing detail lost at each step
- **Gaussian pyramid**: A lowpass pyramid using Gaussian blur as the smoothing filter; each pixel represents a local average of a neighborhood at the level below; used in texture synthesis
- **Laplacian pyramid**: Stores difference images between adjacent Gaussian pyramid levels; only the coarsest level is stored directly (not as a difference), enabling full reconstruction; used in image compression (Burt & Adelson, 1983)
- **Steerable pyramid** (Simoncelli): Multi-scale, multi-orientation bandpass filter bank; orientation-selective variant of the Laplacian pyramid using steerable filters at each level; used in compression, texture synthesis, and object recognition
- **Binomial kernels** (derived from binomial coefficients) are a theoretically well-founded choice for smoothing; the normalized (1/4, 1/2, 1/4) filter applied twice or more per dimension before subsampling is a standard approach
- **Oversampled/hybrid pyramid**: Intermediate scale levels generated by omitting the subsampling step at certain stages
- Pyramids trade off spatial sampling density (resolution) for increased smoothing at each level

## Commands and Syntax

No specific CLI commands from this page, but the computational procedure is:

```
1. Start with original image I_0
2. Apply smoothing filter (e.g., Gaussian or binomial kernel)
3. Subsample by factor 2 in each dimension → I_1
4. Repeat steps 2-3 on I_1 → I_2, etc.

For Laplacian pyramid:
  L_k = I_k - Upsample(I_{k+1})   (difference image at level k)
  Store L_0, L_1, ..., L_{n-1}, and I_n (coarsest level)

Reconstruction:
  I_k = L_k + Upsample(I_{k+1})   (reconstruct from coarse to fine)
```

Binomial smoothing kernel (1D): `[1/4, 1/2, 1/4]` applied typically twice per dimension before subsampling.

## Relationships

- **Scale-space representation**: Pyramids are a predecessor and practical approximation; scale-space decouples subsampling from multi-scale analysis and allows representation at arbitrary scales
- **Multiresolution analysis**: Pyramids are a precursor to formal MRA frameworks (e.g., wavelets)
- **Gaussian blur**: The smoothing operation used in Gaussian pyramids
- **Feature detection**: Pyramids support multi-scale feature computation (LoG, DoG, SIFT); Lowe's SIFT (2004) uses Gaussian pyramids with Difference-of-Gaussians for keypoint detection
- **Mipmaps**: Graphics analog of image pyramids for texture level-of-detail
- **Bilateral filter**: Developed as an alternative to Laplacian pyramid detail manipulation, which produces halo artifacts
- **Image compression**: Laplacian pyramids serve as compact image codes; interlacing schemes (e.g., Adam7 in PNG) function as a kind of pyramid for progressive rendering
- **Texture synthesis**: Both Gaussian and steerable pyramids are used
- **Steerable filters**: The oriented filter bank used within steerable pyramids

## Exam-Relevant Points

- **Two main pyramid types**: lowpass (Gaussian) and bandpass (Laplacian) — know the distinction
- **Gaussian pyramid** smooths and subsamples; **Laplacian pyramid** stores differences between Gaussian levels and enables reconstruction
- **Laplacian pyramid reconstruction** requires only the coarsest Gaussian level plus all difference images
- The standard subsampling factor is **2 in each dimension** (image area reduces by 4x per level)
- **Binomial kernel [1/4, 1/2, 1/4]** is the canonical smoothing filter for pyramid generation
- **Steerable pyramid** adds orientation selectivity to the Laplacian pyramid concept
- Pyramids are **computationally efficient** approximations to continuous scale-space
- Limitation vs. scale-space: pyramids only provide representations at **discrete, fixed scale levels** (powers of 2), not arbitrary scales
- **Detail manipulation** via Laplacian pyramids can produce **halo artifacts**
- Key paper: Burt & Adelson (1983), "The Laplacian Pyramid as a Compact Image Code"
- SIFT (Lowe, 2004) uses pyramid-based Difference-of-Gaussians for scale-invariant keypoint detection
